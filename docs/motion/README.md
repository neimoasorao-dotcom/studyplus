# Motion / Interaction 改善

## 調査と方針

既存のReact / Radix / Recharts / Sonnerを再利用。追加依存なし。ライトとGraphiteのトークン、固定ナビ、計測・保存・同期のデータ形式、分析式を維持する。

| 既存画面・操作 | 課題 | 対応 |
| --- | --- | --- |
| ホーム：今日の実績・目標・学習開始 | 数値と達成率が突然変わる | 実績数値420ms、目標バー、押下フィードバック。計測時計はアニメーションしない |
| 学習：科目・教材一覧、教材詳細、並び順 | 教材が増えると選択が難しい | 既存selectに検索候補を追加。部分一致・全半角正規化・科目絞込・利用回数・最終使用日。保存順は維持 |
| 分析：時間・週間・長期・科目・Balance・Stability・スコア | グラフの更新、タブ、詳細展開の動きが不統一 | 共通の短いフェード、数値・円・棒・線・進捗の描画。時系列・算式・詳細を維持 |
| 記録：検索・30件ページング・編集・削除 | モバイルで各行の操作が見つけづらい | 左スワイプで編集・削除を表示。通常ボタンと削除確認は維持。ジェスチャーだけでは削除しない |
| 管理・目標・模試・AI分析 | 同じ操作の反応が不統一 | 共通モーション、モバイルの設定・詳細シート。ローカルで即時作れる情報には偽のローディングを挟まない |
| 起動時のローカル読込 | 汎用矩形だけで完成画面を予測できない | ホームの実績・入力・グラフに近いSkeleton。待ち時間は追加しない |
| 記録・JSON・同期 | 成功や警告の表示が不統一 | Success / Info / Warning / ErrorのToast、アイコン、閉じる操作。競合と保存失敗は本文にも残す |
| データ・設定、記録入力、詳細 | 中央Modalはスマホで操作しづらい | 767px以下のみBottom Sheet。ハンドルからドラッグ、×、Escape、キーボード操作。データ・設定は62/92dvhのsnap |
| 表示・同期更新 | 手動更新の導線が設定画面内だけ | スマホで下に引く更新＋メニューの同等操作。接続時は既存の同期処理、未設定時は端末内データを再読込 |

現在タスク完了・お気に入り機能はないため、スワイプのために架空の保存項目は追加しない。

## Motion Design System

`styles/motion.css`: Micro 120ms / Component 220ms / Page 280ms / Data 420ms。
通常はcubic-bezier(.2,.7,.2,1)、押下scale .98、シートの短い出現・退場。

- ページ・セクションはopacity中心。固定された学習開始ボタンの祖先にtransformをかけない。
- IntersectionObserverで一度だけセクションを強調。内容を非表示にしてスクロール待ちにしない。
- 数値の確定値は常に支援技術へ提示し、表示幅を確保。ホバー・選択・タイマーの毎秒更新でグラフを再生しない。
- 常時動くのは処理中・読込中など継続中の状態だけ。
- `prefers-reduced-motion`に即時追従。数値・グラフ・スクロール演出を停止する。

## ジェスチャーの安全条件

- Pull: 767px以下、ページ先頭、1本指、本文から開始。横方向、フォーム、グラフ、リストスワイプ、内部スクロール、ダイアログは除外。約132px引いて72pxの表示閾値へ達した時のみ更新。引く途中／離して更新／更新中／完了・失敗を表示。入力中・保存中・未保存・競合時は動かさない。ネイティブのページ全体再読込を抑え、既存の安全な同期を使う。
- Swipe: 10pxの意図判定、横優先1.3倍、52pxの開く閾値。縦スクロールは妨げない。左に開き右に閉じる。編集・削除は通常操作と同じ経路。
- Sheet: 本文をドラッグ対象にしない。ハンドルからのみ操作。拡大・縮小はクリック／上下キーでも利用できる。保存中の閉じる拒否、入力viewport、セーフエリア、Radixのフォーカストラップを維持。
- Autocomplete: Arrow/Home/End/Enter/Escape、IME変換中のEnter保護、0件表示。最初のEscapeは候補のみを閉じる。

## 検証

テストは隔離プロファイル・合成データのみ。実データ・実際の同期リポジトリを使用しない。

```
npx tsc --noEmit
node --test tests/*.test.mjs
npm run build:pages
npm run preview:pages
STUDYPLUS_PLAYWRIGHT_MODULE=/opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright/index.mjs node tests/motion-interactions.browser.mjs
```

`tests/motion-interactions.browser.mjs` はChromiumの実タッチイベントでSwipe/Pull、候補のキーボード操作、シート、Skeleton、Toast、Reduced Motion、データ保持とレスポンシブを検証する。`OFFLINE=1` で単一HTMLをネットワークなしで検証。同期回帰テストは模擬APIのみ。

Windows/iPhone実機の操作感、物理デバイスの60fps、file://直接起動はこの環境では未検証。自動ブラウザのタッチエミュレーションと実機検証を区別する。

デスクトップのシート・タイマー表示、および汎用 `.grid` とダイアログ主レイアウトの競合修正を含む最終成果物に対し、`motion-interactions.browser.mjs` を再実行した。ダイアログ本体は1列を保ち、内部の入力グリッドは既存の構成を維持する。PC・スマホともダイアログの主レイアウトが1列であることもテストで確認した。

| 単一HTML（ネットワーク無効、localhostへのメモリ配信） | PASS | 同じ25画面 |
